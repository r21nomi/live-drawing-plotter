# live-drawing-plotter

Web カメラが捉えた風景を、AxiDraw ペンプロッターでリアルタイムに描き続ける作品です。
ダッシュボードで「開始」を押したあとは、風景が変わるたびに新しい輪郭だけを紙に描き足していきます。以後の操作は要りません。

- 機材: Raspberry Pi 5、USB ウェブカメラ、AxiDraw V3（A4 横）、7 インチ HDMI ディスプレイ（ダッシュボード用）
- 詳しい説明: [運用ガイド](docs/operations.md) / [オプションと調整](docs/options.md) / [開発者向け](docs/development.md)

## 初回のセットアップ（1 回だけ）

1. Raspberry Pi に USB ウェブカメラ、AxiDraw、HDMI ディスプレイをつなぎ、AxiDraw の電源を入れる。
2. このプロジェクトを Pi の `~/live-drawing-plotter` に置く。
3. セットアップスクリプトを実行する（Python 環境、AxiDraw API、シリアル権限、本体とダッシュボードの自動起動の登録をまとめて行います）。

```bash
bash deploy/install-pi.sh
```

4. 再起動する。

```bash
sudo reboot
```

これで、以後は Pi の電源を入れるだけでダッシュボードが立ち上がり、「開始」を押せば描き始めます。

## 日々の運用

### 描画を始める

1. Pi の電源を入れる。1 分ほどでディスプレイにダッシュボードが全画面で出ます（「開始待ち」と表示）。
2. 紙をセットし、ペン先を紙の左上の角（AxiDraw のホーム位置）に合わせる。
3. ダッシュボードの **開始** を押す。

電源を入れただけでは描き始めません。コマンドを打つ必要もありません。

### ダッシュボードで操作する

ディスプレイのダッシュボードには、カメラ映像、紙の状態、抽出した輪郭と、3 つのボタンがあります。
同じ画面は同じ Wi-Fi 内のスマホや PC からも `http://raspberrypi.local:8080` で開けます。

- **開始 / 再開**: 描き始めます。まだ何も描いていないときは「開始」、一時停止からは「再開」と表示されます。
- **一時停止**: 描画中の 1 本を描き終えたらペンを上げて待機します。カメラ映像は流れ続けます。
- **新しい紙**: 描画済みの記憶を消して待機します。紙をセットして「開始」を押すと白紙として描き始めます。

### 本体を止める（電源を切る前に）

```bash
sudo systemctl stop live-plotter@$USER.service
```

描画中の 1 本を描き終えてからペンを上げ、ホームに戻って止まります。再開は `stop` を `start` に替えて実行します。

### 困ったとき

ダッシュボードの状態行に赤字で原因が出ます。本体は自動で再試行し続けるので、原因を取り除けばそのまま復帰します。

- 「カメラが見つかりません」: USB カメラを挿し直す（青い USB 3.0 ポート推奨）。
- 「AxiDraw に接続できません」: AxiDraw の電源と USB を確認する。
- 「AxiDraw が停止しました」: 本体の一時停止ボタンか USB 切断です。キャリッジを手で左上の角に戻してから「開始」を押す。
- 「本体と通信できません」: 本体プロセスが止まっています。`journalctl -u live-plotter@$USER.service -n 50` でログを見る。
- それ以外は [運用ガイド](docs/operations.md) のトラブルシューティングへ。
