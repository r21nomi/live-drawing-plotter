# オプションと調整

`live-plotter --help` でも一覧が出ます。systemd 運用での反映方法は [operations.md](operations.md) を参照。

## 一覧

| オプション | 既定 | 意味 |
|---|---|---|
| `--paper a4\|a3` | a4 | 紙サイズ。AxiDraw のモデル設定も連動（a3 は V3/A3） |
| `--margin` | 10 | 余白 mm |
| `--budget` | 400 | 1 サイクルで描く線長 mm。小さいほど風景の変化に素早く追従 |
| `--min-novelty` | 0.3 | 0〜1。この割合以上が白い場所を通る線だけ描く |
| `--ink-radius` | 1.0 | 描いた線が紙を「占有」する半径 mm。カメラの揺れで同じ線を二度描かないための幅 |
| `--canny LOW HIGH` | 50 150 | エッジ検出の閾値。線が多すぎれば上げる |
| `--blur` | 5 | ぼかしカーネル。ノイズが多ければ上げる |
| `--min-length` | 5 | これより短い線 mm は捨てる |
| `--saturation-threshold` | 0.6 | 紙がこの割合まで埋まったら「飽和」と見なす |
| `--saturation-policy` | continue | 飽和時の振る舞い（下記） |
| `--speed` | 25 | ペンダウン時の速度（%） |
| `--pen-up` / `--pen-down` | 60 / 30 | ペンの上下位置（%） |
| `--mirror` | off | 左右反転（鏡のように描く） |
| `--camera N` / `--source PATH` | 0 | カメラ番号、デバイスパス（`/dev/v4l/by-id/...`）、または動画・画像ファイル |
| `--warmup` | 1.5 | 起動直後に捨てるフレームの秒数（自動露出が安定するまで） |
| `--port` | 自動 | シリアルポート（例 `/dev/ttyACM0`） |
| `--preview` / `--no-preview` | 自動 | プレビュー窓の有無。ディスプレイがなければ自動で無効 |
| `--state-dir DIR` | state | 描画済みの記憶を保存する場所 |
| `--fresh` | off | 保存された記憶を捨てて白紙から始める（紙を替えたとき） |
| `--no-persist` | off | 記憶を保存しない |
| `--dry-run` | off | AxiDraw なしで動かす（開発用） |

## 紙が埋まったとき（`--saturation-policy`）

- `continue`（既定）: そのまま続けます。白い場所がほぼ無くなるので描画はごく少量になり、ほぼ静止します。
- `stop`: ペンを上げてホームに戻り終了します。
- `clear`: 描画済みの記憶を消し、最初から重ね描きします。

## 調整の目安

- **線が多すぎる**: `--canny 80 200` のように閾値を上げる。`--min-length` を 10 にする。
- **線が少なすぎる**: `--canny 30 100` のように下げる。
- **ノイズっぽい短い線が出る**: `--blur` を 7 に、`--min-length` を 10 に。
- **同じ線を何度も描く**: カメラの揺れです。`--ink-radius` を 1.5〜2 に上げるか、`--min-novelty` を 0.5 に。
- **風景の変化への反応を速くしたい**: `--budget` を 200 に下げる（1 サイクルが短くなる）。
- **線を太く／濃く見せたい**: ペンを替えるのが確実です。`--speed` を下げると線が安定します。

調整は Mac で画像ファイルを入力にして試すのが速いです（[development.md](development.md)）。
